# Library Book Borrowing System

## Project Overview

This academic project involved developing a full-stack subscription-based library book borrowing system. The system was designed to allow users to manage library books and borrowing records through a structured web application. The project also involved planning the development process, gathering user requirements and designing a relational database.

## Data Management

The project involved:

- Gathering requirements and feedback from users using Soft Systems Methodology
- Designing and implementing a MySQL database to manage users, books and loan records
- Structuring database tables and relationships to support data integrity
- Managing data related to users, books and borrowing records
- Developing the back-end functionality to interact with the database
- Testing the system to ensure that the website and database worked correctly

## Analysis and Outcomes

The project resulted in a functional full-stack library book borrowing system that allowed users, books and loan records to be managed through a structured database. The project demonstrated experience in relational database design, data integrity, full-stack development, system testing and independent project management.

## Tools Used

- MySQL – Database design and management
- PHP – Back-end development and database interaction
- HTML & CSS – Front-end development
- JavaScript – Website functionality
- Google Sheets & Calendar – Project planning and milestone tracking
